# Mac Creator Lab Research

Public research methods, scorecards, and datasets for evaluating Mac creator workflows.

This repository focuses on practical workflow evaluation rather than feature-count comparisons. The goal is to make tests reproducible: define the task, measure the time and friction required to finish it, and record the conditions that materially affect the result.

## What is here

- `methodology.md` — a reusable workflow-based evaluation protocol.
- `data/workflow-scorecard-template.csv` — a blank scorecard for recording evidence without inventing ratings.
- Future datasets may include dated observations, test environments, and reproducible notes.

## Core workflow categories

1. Product demos
2. Tutorials and documentation
3. Coding walkthroughs
4. Meetings and interviews
5. Long-form courses
6. Short social clips
7. Multi-display recording
8. Captions and transcripts
9. Preview/export consistency
10. Recovery and interruption handling
11. Performance under real load
12. Total time to publish

## Reuse

The methodology and blank scorecard are intended to be adapted for real-world testing. Keep raw observations separate from conclusions, record the test environment, and avoid assigning scores that were not actually measured.
